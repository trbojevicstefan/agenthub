# Opaya: most important management features

- **Every agent in one workspace**: Hermes, Claude Code, Codex, OpenClaw, OpenCode and any OpenAI-compatible API, on this computer, on your VPS machines over SSH, or in Docker containers. Live status, groups, tags, pinning and Connect all.
- **Manage screen per agent**: where it runs, how it is installed (npm, Homebrew, uv, official installer, Hermes profile, Docker), its version, data size and backups, with every action grouped in one place.
- **Update any agent, or all of them**: hourly version checks for every agent and tool (Node.js, Python, Git, uv...) on every machine, an "updates available" chip, and Update / Update all here.
- **Install anywhere in one click**: this computer or any VPS, as a regular install or a Docker container. Opaya brings Node.js, Python and Git itself and shows the exact command first.
- **Machines and VPS**: add a new VPS (Opaya creates the SSH key), import ~/.ssh/config, terminal, files and Discover per machine, Update all agents across every machine.
- **Back up, uninstall, remove**: local .tar.gz backups (with or without history and keys), clean uninstall the way the agent was installed, and a separate Remove connection.
- **Clone and redeploy**: copy a Hermes agent (skills, memory, personality, keys) to this computer, a VPS or Docker, with live progress, speed and time left; redeploy with one click.
- **Share between agents**: transfer skills, API keys (by name only), MCP servers and gateway tokens; a global skills library; MCP servers configured once for all agents.
- **Everything a right-click away**: agent menu with Files & terminal, Skills & tools, Name & look and Maintenance submenus.
- **Opaya Agent that fixes problems itself**: when an agent does not connect, drops or fails, Opaya updates what is too old, starts gateways, finishes setups, and hands the rest to the Opaya Agent in a visible thread with a live checklist.
- **Control and safety**: iTrust per agent or globally, approvals for every change, connection log and diagnostics per agent, credentials in the OS keychain.
